# Gas Management System

A web-based **Gas Management System** developed using **Python Django** to simplify the management of gas cylinder bookings, delivery agents, customers, and administrators.

---

# Features

## Admin Module
- Admin Login
- Dashboard
- Manage Gas Cylinders
  - Add Cylinder
  - Edit Cylinder
  - Delete Cylinder
  - View Cylinders
- Manage Delivery Agents
  - Add Agent
  - Edit Agent
  - Delete Agent
  - View Agents
- View Customer Bookings
- Assign Delivery Agents
- View Customer Feedback

---

## User Module

- User Registration
- User Login
- View Available Cylinders
- Book Gas Cylinder
- View Booking History
- View Booking Status
- Send Feedback
- Logout

---

## Delivery Agent Module

- Agent Login
- View Assigned Orders
- Accept Delivery Request
- Reject Delivery Request
- Mark Delivery as Completed
- View Completed Deliveries
- Logout
